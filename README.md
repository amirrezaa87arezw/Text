# ربات تلگرام تکست‌نویسی رپ فارسی

## چیکار می‌کنه؟

1. **🎤 تکست نوشتن** → انتخاب نسل (۱ تا ۵) → انتخاب رپر مرجع → نوشتن موضوع →
   ربات یه متن رپ فارسی حرفه‌ای، هم‌سبک همون رپر (و بهتر) می‌نویسه.
2. **🎧 فلو شخصی** → فرستادن یه آهنگ + متنش → ربات صدا رو با librosa
   (تمپو/انرژی/رنگ صدا) و متن رو ساختاری تحلیل می‌کنه، پروفایل سبک شخصی
   کاربر رو می‌سازه و از اون به بعد متن‌های جدید دقیقاً با همون فلو می‌نویسه.

## راه‌اندازی محلی (تست قبل از آپلود)

```bash
python -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# .env رو باز کن و BOT_TOKEN و GEMINI_API_KEY رو بذار
python main.py
```

### گرفتن توکن ربات
از [@BotFather](https://t.me/BotFather) توی تلگرام `/newbot` بزن.

### گرفتن API کلید رایگان Gemini
از [Google AI Studio](https://aistudio.google.com/apikey) یه کلید رایگان بگیر
(کوتای رایگان روزانه داره، برای این پروژه کافیه). اگه از ایران وصل نمی‌شه،
با همون VPN که برای ElevenLabs استفاده می‌کنی وصل شو.

## آپلود روی Railway

1. یه پروژه جدید روی Railway بساز و این پوشه رو (یا ریپوی گیت‌هابش رو) وصل کن.
2. توی تب **Variables** همون متغیرهای داخل `.env.example` رو ست کن
   (`BOT_TOKEN`, `LLM_PROVIDER`, `GEMINI_API_KEY`, ...).
3. فایل `nixpacks.toml` باعث میشه Railway خودکار `ffmpeg` رو نصب کنه
   (لازمه چون فایل‌های صوتی تلگرام OGG/Opus هستن).
4. Railway از روی `Procfile` خودش دستور اجرا (`python main.py`) رو تشخیص میده.
5. Deploy بزن. لاگ‌ها رو چک کن که `Run polling` بیاد یعنی ربات بالاست.

> نکته: چون از polling استفاده شده (نه webhook)، نیازی به دامنه یا پورت باز
> نیست؛ روی Railway worker به همین شکل درست کار می‌کنه.

## سفارشی‌سازی

- **لیست رپرها/نسل‌ها**: فایل `rappers.py` — کاملاً قابل ویرایشه، چون
  نسل‌بندی رپ فارسی هیچ مرجع رسمی نداره و بین طرفدارها هم بحثیه.
- **پرامپت‌ها و قوانین نوشتن**: فایل `llm.py` (متغیر `SYSTEM_PROMPT_BASE` و
  توابع `build_generation_prompt` / `build_personal_flow_prompt`).
- **سوییچ بین Gemini/OpenAI/Claude**: فقط `LLM_PROVIDER` رو توی Variables
  عوض کن.

## محدودیت‌های شناخته‌شده

- تحلیل صوتی (`audio_analysis.py`) یه تحلیل تقریبی/heuristic هست (تمپو،
  انرژی، رنگ صدا) نه فهم کامل موسیقی؛ فقط به عنوان سرنخ اضافه به مدل داده
  میشه.
- کیفیت نهایی متن‌ها به کیفیت مدل زبانی انتخابی بستگی داره؛ اگه با Gemini
  راضی نبودی، به‌راحتی می‌تونی `LLM_PROVIDER=claude` یا `openai` کنی (نیاز
  به کلید پولی داره).
