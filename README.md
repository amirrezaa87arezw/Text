# ربات تلگرام تکست‌نویسی رپ فارسی

## چیکار می‌کنه؟

### ۱. 🎤 تکست نوشتن
انتخاب نسل (۱ تا ۵) → انتخاب رپر مرجع → انتخاب حس‌وحال از بین ۸ دکمه
(R&B, گنگ, گنگ فست, دیس‌لاو, دیس‌لاو و اجتماعی, اجتماعی, غمگین, از درد
حرف زدن) → نوشتن چند کلمه برای تمرکز (یا «آزاد») → ربات اول یه
**پیش‌نمایش کوتاه** می‌سازه (یک ورس + هوک) تا حس کار رو ببینی، و اگه
پسندیدی، دکمه‌ی «آهنگ کامل رو بساز» یه **آهنگ کامل و تمام‌عیار** (چند
ورس + هوک تکرارشونده + آوترو) می‌سازه.

### ۲. 🎧 فلو شخصی
فرستادن یه آهنگ + متنش → تحلیل صدا (با librosa) و تحلیل ساختاری متن →
از اون به بعد، با همون مسیر (حس‌وحال + تمرکز + پیش‌نمایش + آهنگ کامل)
می‌تونی متن جدید دقیقاً با فلوی خودت بگیری. چون این متن، متن خود کاربره
(نه اثر شخص ثالث)، کل نمونه‌ی واقعی مستقیم به مدل داده میشه تا سبک رو
واقعاً یاد بگیره.

### ۳. 🎵 نوشتن روی بیت (جدید)
فرستادن یه بیت (موزیک بی‌کلام) → تحلیل تمپو/انرژی/رنگ صدا → همون مسیر
حس‌وحال + پیش‌نمایش + آهنگ کامل، این بار هماهنگ با ریتم بیت ارسالی.

### 🎙 بشنو چطوری میشه
بعد از ساخت آهنگ کامل، دکمه‌ی «بشنو چطوری میشه» یه ویس می‌سازه که متن
رو می‌خونه (با ElevenLabs) تا حس تلفظ و ریتم کلی رو بگیری. **مهم: این
فقط یه خوانش گفتاری معمولیه، نه یه اجرای واقعی رپ هماهنگ‌شده با BPM
بیت** - چیزی که هیچ TTS ای در حال حاضر واقعاً نمی‌تونه انجام بده.

### ✨ بهترش کن
هر آهنگی که ساخته میشه، از یه موتور دومرحله‌ای رد شده (پیش‌نویس + یک
دور ویرایش خودکار با چک‌لیست حرفه‌ای). دکمه‌ی «بهترش کن» یه دور دیگه هم
دستی روی همون متن اعمال می‌کنه.

## راه‌اندازی محلی (تست قبل از آپلود)

```bash
python -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# .env رو باز کن و BOT_TOKEN و GEMINI_API_KEY رو بذار
python main.py
```

### گرفتن توکن ربات
از [@BotFather](https://t.me/BotFather) توی تلگرام `/newbot` بزن.

### گرفتن API کلید رایگان Gemini
از [Google AI Studio](https://aistudio.google.com/app/apikey) یه کلید
رایگان بگیر. اگه از ایران وصل نمی‌شه، با VPN امتحان کن (بعضی سرورها رو
گوگل بلاک می‌کنه، سرور عوض کن). مدل پیشنهادی الان: `gemini-3.6-flash`
(مدل‌های قدیمی‌تر مثل `gemini-2.5-flash` دیگه برای کاربر جدید در دسترس
نیستن).

### گرفتن API کلید ElevenLabs (اختیاری، برای قابلیت ویس)
از پنل ElevenLabs (همونی که برای تگ‌های پروڈیوسری استفاده می‌کنی) یه
API Key و یه Voice ID بردار و توی `ELEVENLABS_API_KEY` /
`ELEVENLABS_VOICE_ID` بذار. اگه خالی بمونه، فقط دکمه‌ی «بشنو چطوری میشه»
با خطا مواجه میشه، بقیه‌ی ربات عادی کار می‌کنه.

## آپلود روی Railway

1. یه پروژه جدید روی Railway بساز و این پوشه رو (یا ریپوی گیت‌هابش رو) وصل کن.
2. توی تب **Variables** همون متغیرهای داخل `.env.example` رو ست کن.
3. فایل `nixpacks.toml` باعث میشه Railway خودکار `ffmpeg` رو نصب کنه
   (لازمه هم برای فایل‌های صوتی OGG تلگرام و هم برای تبدیل ویس خروجی).
4. Railway از روی `Procfile` خودش دستور اجرا (`python main.py`) رو تشخیص میده.
5. Deploy بزن. لاگ‌ها رو چک کن که `Run polling` بیاد یعنی ربات بالاست.

## سفارشی‌سازی

- **لیست رپرها/نسل‌ها**: فایل `rappers.py` — کاملاً قابل ویرایشه.
- **حس‌وحال‌ها**: فایل `moods.py` — می‌تونی حس‌وحال جدید اضافه کنی یا
  توصیف سبکی هر کدوم رو دقیق‌تر کنی.
- **پرامپت‌ها و قوانین نوشتن**: فایل `llm.py`.
- **سوییچ بین Gemini/OpenAI/Claude**: فقط `LLM_PROVIDER` رو عوض کن.

## محدودیت‌های شناخته‌شده

- تحلیل صوتی (بیت یا آهنگ مرجع) یه تحلیل تقریبی/heuristic هست (تمپو،
  انرژی، رنگ صدا)، نه فهم کامل موسیقی.
- ویس خروجی یه خوانش گفتاری معمولیه، نه یه اجرای رپ واقعی هماهنگ با بیت.
- کیفیت نهایی متن‌ها به کیفیت مدل زبانی انتخابی بستگی داره.
- به دلیل قوانین کپی‌رایت، متن واقعی هیچ رپری (فقط توصیف سبکی) توی کد
  نیست؛ فقط نمونه‌ی متن خود کاربر (در بخش فلو شخصی) مستقیم استفاده میشه
  چون مال خودشه.
